# LITFEST 2.0 frontend

The frontend includes the sponsors page and a React contact form, built with
React, TypeScript, and Vite. The contact page is available at `/contact` and
`/ContactUs.html`.

## Development

From this directory, install dependencies and start the development server:

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create a production build, or
`npm run lint` to lint the frontend.
