# LITFEST 2.0 frontend

The frontend uses React, TypeScript, and Vite. It includes the underwater
homepage, a sponsors page, and a contact page.

## Development

From this directory, install dependencies and start the development server:

```sh
npm install
npm run dev
```

The homepage is served at `/`, the contact page at `/contact`, and the sponsors
page at `/sponsors`. The legacy `/ContactUs.html` and `/Sponsors.html` paths
continue to work.

Run `npm run build` to type-check and create a production build, or
`npm run lint` to lint the frontend.
